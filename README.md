Galaxy — Dynamic Starfield & Audio Visualizer
A lightweight, interactive 2D galaxy and starfield simulator built using pure HTML5 Canvas, CSS, and the Web Audio API. No external dependencies or libraries required.🌐 Live Demo: https://yourdomain.com🌟 FeaturesInteractive Galaxy Morphing: Instantly transition between 4 distinct galactic structures:Spiral: Classic multi-arm rotating spiral galaxy.Elliptical: Dense spherical star distribution.Ring: Ring-shaped star cluster encircling a quiet core.Cluster: Tri-core star group.Dynamic Starfield & Parallax: Background stars respond dynamically to mouse movements, creating a sense of depth and perspective.Orbital Planetary Systems: 5 planets orbiting the galactic core, complete with custom shading, glow effects, orbiting moons, and planetary rings.Generative Ambient Soundtrack: Built-in procedural ambient synthesizer powered by the Web Audio API (smooth ambient chord pads and interactive pluck melodies).Shooting Stars & Particle Bursts: Random meteor occurrences across the night sky, plus interactive starbursts generated on click.Fully Responsive: Scales automatically to any screen size and viewport resize.🚀 Quick StartSince this project uses native web technologies, no build tools or installations are required.Visit the live site at https://yourdomain.com or clone/download this repository.Open galaxy.html directly in any modern web browser (Chrome, Firefox, Safari, Edge).🎮 Controls & InteractionsActionControlParallax ViewMove mouse around the screenStar Burst / Enable AudioLeft Click anywhereGalaxy MorphingPress keys 1–4 or use the top-right UI buttonsToggle Ambient AudioPress M key or click the sound button🛠️ Technical DetailsRendering Engine: Vanilla JavaScript utilizing HTML5 <canvas> 2D Context (requestAnimationFrame render loop).Audio Engine: Pure Web Audio API generating real-time sine and triangle waves, filtered lowpass delays, and dynamic chord progression sweeps.Styling: CSS3 for overlays, animations, and responsive UI overlays.📄 LicenseThis project is open-source and available under the MIT License.
